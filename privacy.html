헬스 브릿지 개인정보처리방침

시행일: 2026년 11월 24일

헬스 브릿지(이하 "앱")는 개발자 본인이 개인적으로 사용하기 위해 만든 안드로이드 앱입니다. 앱은 사용자의 기기에 저장된 건강 기록을 사용자 본인의 구글 드라이브로 옮기는 기능만 합니다.

1. 읽는 정보

사용자가 허용한 경우에만 Android Health Connect에서 다음 기록을 읽습니다: 걸음 수, 이동 거리, 소모 칼로리, 심박수, 안정시 심박수, 심박변이도, 혈중산소, 수면, 체중, 키, 체지방률, 제지방량, 체수분, 기초대사량, 운동 기록.

앱은 Health Connect의 기록을 만들거나 수정하거나 삭제하지 않습니다.

2. 정보를 쓰는 곳

읽은 정보는 사용자가 로그인한 본인 구글 드라이브의 "HealthBridge" 폴더에 JSON 파일로 저장됩니다. 구글 드라이브 권한은 drive.file로, 앱이 만든 파일에만 접근할 수 있으며 다른 드라이브 파일은 보거나 수정할 수 없습니다. 구글 계정 이메일은 같은 계정으로 다시 연결하기 위해서만 기기에 저장됩니다.

3. 제3자 제공

앱은 개발자나 다른 어떤 서버로도 정보를 보내지 않으며, 광고·분석 도구를 포함하지 않습니다. 정보를 판매하거나 공유하지 않습니다.

4. 보관과 삭제

드라이브에 저장된 파일은 사용자가 직접 관리하며, 언제든 삭제할 수 있습니다. Health Connect 권한은 기기 설정의 Health Connect에서, 구글 드라이브 접근 권한은 구글 계정의 "타사 앱 및 서비스" 설정에서 언제든 해제할 수 있습니다. 앱을 삭제하면 기기에 남은 설정도 함께 삭제됩니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한된 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
